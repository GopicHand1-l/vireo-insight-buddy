# Vireo Insights Hub

The main aim is to build a working AI-assisted dashboard tool for Vireo Audio. So, CSAT per agent, handle time per agent, flag bottom performers, but with fairness checks, not naïve ranking. Then, translate that into a measurable business goal with a rupee impact, validate your AI outputs, and submit the required one page memo, short recording, and filled form.
